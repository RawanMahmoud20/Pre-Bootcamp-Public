# MySQL Countries Assignment

## Project Overview
This project contains a set of SQL queries developed for the **world database**. The objective is to practice and demonstrate proficiency in writing complex SQL queries, including data retrieval, joining multiple tables, and using aggregate functions.

## Database Schema
The analysis is based on three main tables:
1. `countries`: Contains geographical and political data.
2. `cities`: Contains information about cities and their populations.
3. `languages`: Contains information about languages spoken in different countries.

## Requirements
- MySQL Server
- MySQL Workbench (or any SQL client)
- `world.sql` database file

## Queries Performed
The solution includes 8 queries addressing:
- Filtering records based on multiple conditions.
- Joining tables using Foreign Keys.
- Aggregating data using `COUNT` and `GROUP BY`.
- Sorting results using `ORDER BY`.

## How to Run
1. Import the `world.sql` file into your MySQL server.
2. Copy the queries from the solution script into your SQL editor.
3. Execute the queries to view the results.
