# Assignment: Sakila Database Analysis

## Description
This repository contains SQL solutions for the Sakila database assignment. The focus is on mastering relational database queries, specifically using multiple `JOIN` operations to connect films, actors, customers, and categories.

## Objectives
*   Extracting targeted data using `WHERE` and `IN` clauses.
*   Mastering `INNER JOIN` across 3 or more tables.
*   Utilizing pattern matching with the `LIKE` function.
*   Handling real-world database naming conventions.

## Tools Used
*   **MySQL Workbench**: For writing and executing queries.
*   **Sakila Sample Database**: A standardized complex schema for testing.

## Key Learning Points
- **Table Relationships**: Understanding how `film_actor` and `film_category` act as junction tables.
- **Data Filtering**: Combining multiple logical operators (`AND`, `IN`) to narrow down results.
- **String Manipulation**: Using `CONCAT` for cleaner output of full names.
