# Zoo Management System 

This project is built using Object-Oriented Programming in Python.

## Features:
- Add animals to zoo
- Display animal information
- Feed animals using polymorphism

## Concepts used:
- Inheritance
- Polymorphism
- Classes and Objects

## How to run:
1. Using Python
Install Python from: https://www.python.org/downloads/
Open the project folder.
Open the terminal inside the folder.
Run:
python main.py
If it doesn’t work, try:
python3 main.py


2. Using Visual Studio Code
Install VS Code.
Install the Python Extension.
Open the project folder.
Click Run ▶ or choose Run Python File.
