# Singly Linked List Implementation

This project is a basic implementation of the Singly Linked List data structure using Python.

## Features
- add_to_front: Adds an element to the beginning of the list.
- add_to_back: Adds an element to the end of the list.
- print_values: Prints all elements in the list.

## How to Use

You can use method chaining to easily add elements:
my_list = SList()
my_list.add_to_front("A").add_to_back("B").print_values()
