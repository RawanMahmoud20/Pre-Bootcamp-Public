# Flask Counter App 🚀

A simple web application built with **Flask** and **Python** to demonstrate the use of **Client-Side Sessions**. This app tracks how many times a user has visited the page.

## 📌 Features
- **Visit Counter:** Increments by 1 every time the page is refreshed.
- **Session Management:** Uses browser-based sessions to store data uniquely for each user.
- **Reset Functionality:** A "Destroy Session" route that clears all session data and resets the counter.
- **Bootstrap UI:** Styled with a clean, responsive interface.
