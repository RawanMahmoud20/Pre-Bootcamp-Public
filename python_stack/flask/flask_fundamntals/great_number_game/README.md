# Great Number Game 🔢

A fun, interactive web-based guessing game built with **Python** and **Flask**. The application challenges users to guess a randomly generated number between 1 and 100, providing real-time feedback.

## 📌 Features
- **Random Number Generation:** A new secret number is generated for every session.
- **Dynamic Feedback:** - 🟥 **Red box:** If the guess is too high or too low.
    - 🟩 **Green box:** If the guess is correct, displaying the number and attempts.
- **Attempt Tracking:** Keeps count of how many guesses the user made.
- **Client-Side Validation:** Uses HTML5 attributes (`min` and `max`) to ensure inputs stay within the 1-100 range.
- **Play Again:** Easily reset the game to start over with a new number.
