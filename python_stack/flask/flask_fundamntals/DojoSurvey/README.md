Dojo Survey - Flask Assignment
This project is a simple web application built using the Flask framework. The application collects data from a form via a POST request and displays the submitted information on a results page.

🚀 Key Features
Home Page (/): Displays a well-designed form to collect user input.

Results Page (/result): Displays the information submitted by the user.

🛠️ Requirements
Python 3.x

Flask

📥 How to Run
Create and navigate to the project directory:

Bash
mkdir dojo_survey
cd dojo_survey
Install the required packages:

Bash
pip install Flask==3.0.0
Create the following project structure and files:

server.py

templates/index.html

templates/result.html

Run the application:

Bash
python server.py
Open in your browser:
Go to: http://localhost:5000/
