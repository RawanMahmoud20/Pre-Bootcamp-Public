# Ninja Gold 

A mini-game built with **Python** and **Flask** where you play as a ninja trying to accumulate as much gold as possible by visiting different locations.

## 📌 Game Mechanics
- **Farm:** Earns 10-20 gold (Safe).
- **Cave:** Earns 5-10 gold (Safe).
- **House:** Earns 2-5 gold (Safe).
- **Casino:** Earns or loses up to 50 gold (Risky!).

## 🚀 Features
- **Centralized Processing:** Uses a single POST route with **Hidden Inputs** to handle multiple forms.
- **Activity Log:** Keeps a detailed, color-coded history of all your moves (Green for gains, Red for losses).
- **Session Persistence:** Your gold and history are saved even if you refresh the page.
- **Reset Option:** Clear all data and start your ninja journey from scratch.
