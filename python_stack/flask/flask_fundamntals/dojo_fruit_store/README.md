# Dojo Fruit Store - Flask Assignment

This project is a small web application built using **Flask** to handle fruit orders and display order summaries.

## Key Features
- **Order Form (`/`):** Allows users to select fruit quantities and enter personal information.
- **Checkout Page (`/checkout`):** Processes the order via a `POST` request and displays the summary details.

##  Requirements
- Python 3.x
- Flask
