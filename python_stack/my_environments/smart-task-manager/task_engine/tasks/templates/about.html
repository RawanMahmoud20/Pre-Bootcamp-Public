Smart Task Management System

A full-stack productivity platform built on Django MVT architecture, designed to help individuals track, prioritise, and complete work with clarity.

Our Engineering Goals

  • Workspace Isolation — every user's tasks are strictly scoped to their own workspace with FK-enforced ownership checks at every query.
  • AJAX-First UX — status changes, creates, and deletes happen asynchronously via the Fetch API without full page reloads.
  • Security by Default — CSRF tokens on every mutating request, server-side ownership guards, and input sanitisation throughout.
  • Transactional Emails — welcome messages and deadline alerts dispatched via Django's email framework with an HTML template layer.

Relational Schema Overview
users
id · username · email · password

Custom AbstractUser — anchors workspace ownership.

tasks
id · title · description · due_date · status · user_id(FK)

Core entity. Status: Pending → In Progress → Completed.

categories
id · name

Work, Personal, Urgent — classification metadata.

task_assignments
id · task_id(FK) · user_id(FK) · assigned_at

Audit log: who was assigned to which task and when.

task_categories
id · task_id(FK) · category_id(FK)

Explicit junction — models M2M without Django's auto table.
