# Simple Blog Database System

## Description
This project implements the backend database structure for a "Simple Blog" application based on provided wireframes. It covers user authentication storage, blog post management, and a commenting system with full relational integrity.

## Schema Design
The database consists of three main entities:
- **Users**: Stores credentials for login and registration.
- **Posts**: Stores blog content linked to a specific user.
- **Comments**: Stores feedback on posts, linked to both a user and a post.

## Technologies Used
- MySQL / MariaDB
- Relational Database Design (ERD)

## How to Run
1. Copy the SQL code from the solution file.
2. Run it in your MySQL workbench or terminal.
3. Use the provided "Dummy Data" section to verify the relationships between tables.
